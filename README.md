# Noor Osman, Portfolio

Portfolio website for Noor Osman, brand & packaging designer.

- Single page, no build step: open `index.html` or visit the GitHub Pages link.
- English and Dutch, with a language switch in the navigation.
- Project images live in `img/` (SVG). Replace them with real photos or mockups when available.
- Personal details (email, Instagram, location) are set in the `ME` block at the top of `index.html`; all copy is in the `T` block near the bottom.
